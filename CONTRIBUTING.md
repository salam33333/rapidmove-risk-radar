# Contributing

Thanks for your interest in improving RapidMove Risk Radar.

## Ways to contribute

- Report a reproducible bug or incorrect indicator behavior in GitHub Issues.
- Test the indicator on a supported MT5 broker, symbol, and timeframe. Include the terminal build, broker symbol, timeframe, and relevant compiler or journal output.
- Propose focused code or documentation changes through a pull request.

## Before opening an issue

Include the MT5 terminal and MetaEditor build numbers, broker and exact symbol name, timeframe and indicator inputs, steps to reproduce, and relevant compiler or Experts log output. Remove account details and personal information.

## Pull requests

- Keep changes focused and explain the problem they solve.
- Describe how you tested the change. Do not claim MetaEditor compilation unless you actually compiled it.
- Do not add broker account credentials, private trade history, or personal data.
- Do not present the indicator as a buy/sell signal or a profitable strategy. It ranks relative risk and does not predict direction.

## Testing status

The project has not yet been compiled in MetaEditor by the maintainer. Contributions that verify compilation on a stated MetaTrader 5 build are especially useful.
